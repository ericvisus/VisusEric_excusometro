¿Qué es el Excusómetro?

Esta web sirve para recopilar excusas típicas que usamos cuando no hacemos una tarea o algo no funciona.

Las excusas se analizan de forma divertida para ver si parecen creíbles o no.

¿Qué excusas hay?

  • Problemas con el ordenador.
  • Olvidarse de entregar un trabajo.
  • Problemas con internet.

Lista de excusas

Estas son algunas excusas que se escuchan bastante en clase.

“No me iba el ordenador”

Puede ser verdad, pero siempre pasa justo antes de entregar.

“Pensaba que era para mañana”

Una excusa típica cuando se nos olvida la fecha.

“No se me ha guardado el archivo”

El trabajo estaba hecho, pero ahora no aparece por ningún sitio.

“No tenía internet”

La conexión falla justo cuando hay que subir la tarea.

“Lo tengo en casa”

El trabajo existe, pero se ha quedado en otro sitio.

Cómo analizamos una excusa

Para analizar una excusa seguimos estos pasos:

  1. Escuchar la excusa.
  2. Mirar si tiene sentido.
  3. Comprobar los detalles importantes.
  4. Decidir si parece creíble o sospechosa.
